# 往新项目接入这套机制（3 步，约 2 分钟）

> 规则本身见 `SKILL.md`；这里只讲**怎么把机械检查装进一个项目**。

## 需要拷什么

本 skill 目录里自带通用版工具（不含任何项目知识 ✓）：

| 文件 | 作用 |
|---|---|
| `provenance_check.py` | 引擎：搜索可调数值，要求每个写明「来历」 |
| `provenance.example.json` | 配置模板：换项目只改这个 ✗→✓ |
| `run_all_selftests.py` | 一条命令跑全部自检（自动发现套件） |

## 三步接入

```bash
# ① 拷两个工具到项目的 tools/（或任何目录）
cp <skill>/provenance_check.py        <项目>/tools/
cp <skill>/run_all_selftests.py       <项目>/tools/

# ② 拷配置模板并改两行：scan 写要扫哪些文件；assumptions_out 写清单放哪
cp <skill>/provenance.example.json    <项目>/tools/provenance.json
#   改 scan:        ["src/**/*.py"] 之类
#   改 tags:        英文项目可用 "basis: measured" 等
#   改 assumptions_out: "docs/unmeasured.json" 之类

# ③ 跑一次，把清单生出来
python <项目>/tools/provenance_check.py --write-assumptions
```

## 可选：拦住提交

```bash
mkdir -p <项目>/tools/git-hooks
cat > <项目>/tools/git-hooks/pre-commit <<'EOF'
#!/bin/sh
set -e
PY=python; command -v $PY >/dev/null 2>&1 || PY=python3
$PY tools/provenance_check.py >/dev/null || {
  echo "✗ 提交被拦下：有数值没写「来历」"
  echo "  查看：python tools/provenance_check.py --audit"
  echo "  三态：依据: 实测 … / 依据: 机制 … / 依据: 未实测 …"
  exit 1
}
echo "[pre-commit] OK"
EOF
cp <项目>/tools/git-hooks/pre-commit <项目>/.git/hooks/pre-commit
chmod +x <项目>/.git/hooks/pre-commit
```

## 可选：往项目 AGENTS.md 里粘这段

```markdown
## 数值纪律

每个可调数值必须写「来历」，三态之一（由 `python tools/provenance_check.py` 强制检查）：

    TIMEOUT_S = 3.0       # 依据: 实测（n=30，见 docs/measured.json）
    STEP_PX = 8.0         # 依据: 机制（由格粒度决定）
    WINDOW_S = 45         # 依据: 未实测（初值，见 docs/unmeasured.json）

只写"描述"不算依据 ✗。任何当依据用的数字必须能追到「实测档案」或「未实测清单」；
追不到就必须在回复里当场说明"这是初值" ✗→✓
```

## 配置字段速查

| 字段 | 含义 |
|---|---|
| `scan` | 要扫描的 glob（相对项目根）|
| `exclude` | 排除的 glob（用 `**` 通配）|
| `tags` | 三态/语义的关键字（可多语言：`basis: measured` 等）|
| `lookback_lines` | 往上找标签的行数（默认 6）|
| `exempt_name_patterns` | 免检的名字正则（私有状态/时间戳）|
| `exempt_self_names` | 免检的 `self.x` 名字 |
| `semantic_names` | 语义常量名（状态码等，不算可调）|
| `logic_values` | 免检的逻辑小整数（默认 0/1/2/-1）|
| `assumptions_out` | 未实测清单写到哪 |
| `premise` | 该清单顶部声明的前提（如"模板=xxx"）|

## 它做不到什么（别误解）

- 只搜 4 种写法：模块级常量 / `self.x = 数字` / 数值表 / `__init__` 签名默认值；
  函数体内的行内字面量（`x = a * 0.5`）**不搜** ✗（有意收窄以降低误报）
- 只查"**有没有来历**"，**不查"值对不对"** ✗
- 抓不到**回复/文档里**的错误断言 ✗（那靠 SKILL.md 的行为规则 + 人工抽查）
