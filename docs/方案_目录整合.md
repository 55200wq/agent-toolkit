# 方案 v2：agent-toolkit 作为**可发布的 Agent 工具集**

> 状态：**待评审**（v1 已部分实现；v2 修正定位与结构）
> 用户 2026-10-15 修正：「不光 tools 要放到 agent-tools，**skill 也要，AGENTS 也要**，
> 要将这些**完整实现**都放过去并且**按功能分子目录**，以后会将这个 agent-tools **发布到 github**，
> 能够做到**从 github 下拉安装**让别的人的 agent 也能够使用」

---

## §1 v1 错在哪

| v1 的做法 | 问题 |
|---|---|
| agent-tools 只放 tools + install + docs ✗ | skill 留在 `~/.dsh/skills/`、AGENTS 留在各项目里 ⇒ **实现仍然分散** ✗ |
| skill 只当"规则指针" ✗ | 别人 clone 之后**拿不到规则** ⇒ 无法给别的 agent 用 ✗ |
| 没有发布形态 ✗ | 没有 LICENSE / 没有面向外部用户的 README / 没有一行安装 ✗ |

## §2 v2 的目标（可发布、可安装、按功能分目录）

```
任何人（或任何 agent）：
   从 GitHub 拉下来 → 一条命令 → ① 装进他的项目 ② 装进他的 agent 的 skills 目录
```

**验收**

| # | 判据 |
|---|---|
| A1 | 仓库里含**完整实现**：工具 + skill + AGENTS 模板 + 安装器 + 文档 ✓ |
| A2 | 目录**按功能分**（每个功能一个子目录，自带 README 与自测 ✓）|
| A3 | 一条命令把工具装进任意项目 ✓（`install.py --project <dir>`）|
| A4 | 一条命令把 skill 装进任意 agent 的 skills 目录 ✓（`--skills-dir`，含 DSH 默认值）|
| A5 | 一条命令把 AGENTS 规则片段**幂等**地写进项目 ✓（有标记，不重复追加 ✓）|
| A6 | 从 GitHub 一行安装（`install.sh` / `install.ps1`）✓ |
| A7 | 未指定 LICENSE 时不猜（见 §7）|
| A8 | sift_match 现有行为不变（自检全绿、37 项清单、钩子仍拦 ✓）|

## §3 目标结构（按功能分子目录）

```
agent-toolkit/                      ← 将要发布到 GitHub 的仓库（本地目录与仓库同名）
├── README.md                       面向外部用户：这是什么 / 为什么 / 怎么装 / 怎么用
├── LICENSE                         ★ 待定（见 §7）
├── VERSION · CHANGELOG.md
├── skills/                         ★ 功能一：agent 规则（可安装到任意 agent）
│   └── measured-or-flagged-zh/
│       └── SKILL.md                    规则：数值必须有来历（三态）
├── tools/                          ★ 功能二：可执行工具（每个一目录，自带自测）
│   ├── provenance/                     数值溯源自检
│   └── selftests/                      自检汇总器
├── templates/                      ★ 功能三：往项目里放的东西
│   ├── AGENTS.snippet.md               规则片段（幂等插入项目 AGENTS.md）
│   ├── pre-commit                      钩子
│   ├── provenance.example.json
│   └── selftests.example.json
├── install/                        ★ 功能四：安装
│   ├── install.py                      装工具 / 装 skill / 写 AGENTS / --check
│   ├── install.sh                      GitHub 一行安装（Linux/macOS）
│   └── install.ps1                     GitHub 一行安装（Windows）
└── docs/                           ★ 功能五：文档
    ├── 数值纪律.md                     规则正文
    ├── 接入清单.md                     三步接入（含各 agent 的 skills 路径）
    └── 方案_目录整合.md                本文件（含 v1/v2 修订记录）
```

**"按功能分子目录"的含义**：每个子目录 = 一个**可独立理解、独立测试、独立安装**的功能单元 ✓
（`skills/` 装规则、`tools/` 装程序、`templates/` 装要粘进项目的东西、`install/` 只负责装、`docs/` 只讲道理 ✓）

## §4 安装器的契约（面向"别人的 agent"）

```bash
# ① 从 GitHub 一行安装（clone 到临时目录 → 跑 install.py）
curl -fsSL https://raw.githubusercontent.com/55200wq/agent-toolkit/main/install/install.sh | bash
#   Windows: irm https://raw.githubusercontent.com/55200wq/agent-toolkit/main/install/install.ps1 | iex
#   或者：git clone <repo> && python agent-toolkit/install/install.py --all

# ② 装进项目（工具 + 可选 AGENTS 片段 / 钩子）
python install.py --project <项目根> [--with-agents] [--with-hook]

# ③ 装 skill 到 agent 的 skills 目录（DSH 默认 ~/.dsh/skills；其他 agent 用 --skills-dir）
python install.py --skills [--skills-dir <目录>]

# ④ 全部装（项目 + skill）
python install.py --all --project <项目根>

# ⑤ 漂移检查（一致0 被改1 落后2 未装3）
python install.py --project <项目根> --check
```

| 退出码 | 含义 |
|---|---|
| 0 | 成功/一致 ✓ |
| 1 | 项目副本被本地改过 ✗ |
| 2 | 落后于工具集 ✗ |
| 3 | 未安装 / 参数缺失 |

**幂等要求**：AGENTS 片段用标记包裹（`<!-- agent-tools:begin -->…<!-- agent-tools:end -->`）✓
重复安装不重复追加 ✓、内容变化时**替换**该段 ✓

## §5 别处怎么同步（三处角色，v2 修订）

| 位置 | 保留 | 说明 |
